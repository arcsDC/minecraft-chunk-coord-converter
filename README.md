# minecraft-chunk-coord-converter

A Fabric mod that displays the current chunk coordinates in the debug overlay for easier world navigation.

## Stack

Primary language: **Java**

## Project structure

- `src/main/java/com/example/chunkcoords/ChunkCoordsMod.java` — Injects chunk X/Z coordinates into the F3 debug screen.
- `build.gradle` — fabric build config

## Usage

Review the source files and install any dependencies referenced by the project before running it.
